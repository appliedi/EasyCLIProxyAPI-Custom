## Нумерация версий

- Пользовательские выпуски теперь следуют версии настольного приложения из основного проекта. **1.3.117** основана на версии **0.3.117**; ведущая 1 обозначает этот дистрибутив. Собственные исправления между выпусками основного проекта получают номера 1.3.117+1, 1.3.117+2 и т. д. (в Windows они отображаются как 1.3.117.1, 1.3.117.2).
- Установленные версии 0.4.x воспринимают 1.3.117 как обычное обновление.

## Обновлено

- Интегрированы EasyCLIProxyAPI v0.3.117 и встроенное ядро CLIProxyAPI 8.0.78, включая так и не опубликованную интеграцию 0.4.4 (v0.3.99).
- На странице OAuth появился доступ ACP для Antigravity: сохранение нескольких аккаунтов, явный переключатель запуска и остановки API, вызовы инструментов и потоковая передача.
- В управлении версиями добавлены необязательные фоновые автоматические обновления. Обновления приложения по-прежнему поступают только из этого репозитория, а ядро обновляется из официальных выпусков CLIProxyAPI.
- Добавлены редактирование системных промптов для каждого агента, правила замены чувствительных слов, импорт пользовательских тем, обновлённый вид живой маршрутизации и редактор цен моделей с поиском.
- Включены уведомления об обновлениях плагинов, улучшения магазина плагинов, доработки квот, восстановление обратного прокси и множество исправлений для учёта использования, ZCode, Codex и Claude Desktop.

## Сохранено

- Страницы использования и стоимости подписок с сохранёнными тарифами, хранение и резервное копирование данных, приоритеты аккаунтов и привязка сессий, а также установщик Windows переносятся без изменений.

## Изменено

- Облачные правила чувствительных слов загружаются из этого репозитория, а не из основного проекта.
- Ручные модели ZCode без выбранных уровней рассуждения при записи в ZCode получают список low/medium/high, потому что ZCode отклоняет пустой список и отбрасывает всю конфигурацию провайдера. В редакторе по-прежнему отображается ваш пустой выбор.

## Совместимость

- Пользовательские навыки ищутся в папке `skills` приложения. Существующие навыки из `$HOME/.easy-cli-proxy-api/skills` может потребоваться скопировать туда.
