## 版本號

- 自訂版本現在跟隨上游桌面版本。**1.3.117** 以上游 **0.3.117** 為基礎，開頭的 1 代表本發行版。兩個上游版本之間的自訂修正依序編號為 1.3.117+1、1.3.117+2 等（Windows 顯示為 1.3.117.1、1.3.117.2）。
- 已安裝的 0.4.x 版本會將 1.3.117 視為一般更新。

## 更新

- 整合 EasyCLIProxyAPI v0.3.117，內建 CLIProxyAPI 核心 8.0.78，並包含未單獨發布的 0.4.4（v0.3.99）整合內容。
- OAuth 頁面新增 Antigravity 的 ACP 存取，支援儲存多個帳號、明確啟動/停止 API、工具呼叫與串流輸出。
- 版本管理新增可選的背景自動更新。桌面更新仍只來自本儲存庫，核心更新來自官方 CLIProxyAPI 發布。
- 新增依用戶端編輯系統提示詞、敏感詞替換規則、匯入自訂主題、重新設計的即時路由檢視，以及可搜尋的模型價格編輯器。
- 包含外掛更新提示、外掛商店改進、配額改善、反向代理復原，以及大量用量、ZCode、Codex 與 Claude Desktop 修正。

## 保留

- 訂閱用量、訂閱價值與已儲存費用、儲存與備份、帳號優先順序與工作階段親和控制，以及 Windows 安裝程式皆維持不變。

## 變更

- 敏感詞雲端規則改為從本儲存庫下載，不再使用上游儲存庫。
- 未選擇推理等級的 ZCode 手動模型寫入 ZCode 時會使用 low/medium/high 清單，因為 ZCode 會拒絕空清單並捨棄整個提供者設定。編輯器中仍顯示你的空選擇。

## 相容性

- 自訂技能從應用程式的 `skills` 資料夾中探索。`$HOME/.easy-cli-proxy-api/skills` 下的現有技能可能需要複製過去。
