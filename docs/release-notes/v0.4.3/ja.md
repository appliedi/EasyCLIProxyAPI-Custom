# Custom 0.4.3

- 上流デスクトップ版 **0.3.76** を統合し、公式 CLIProxyAPI **8.0.52** を同梱しました。エージェント検出の性能修正、クォータ改善、エージェント使用履歴、ルーティング、MCP・スキル管理、テーマ、リバースプロキシを含みます。
- 独立した **Subscription Usage**、アカウント優先度、セッション親和性、月単位の料金履歴と価格カバレッジを扱う **Subscription Value** を維持しました。
- 高度な機能に保存先とバックアップを追加しました。更新後も保存先を維持し、検証済みバックアップと復元には使用量、料金、認証情報、エージェント履歴、MCP・スキル設定、テーマ、設定を含めます。SQLite のコミット済み WAL データも保持します。
- ポータブル ZIP に加え、Windows ユーザー単位の **Setup.exe** を追加しました。既存のポータブル保存先を選択でき、再インストールとアンインストール後も個人データを保持します。
- 公開前に、上流由来の UI・翻訳、リリースツール、Windows テストの互換性問題を修正しました。
- デスクトップ更新とモデルカタログは Custom リポジトリ、プロキシコア更新は公式リポジトリを使用します。

## 更新方法

Custom 0.4.0/0.4.1/0.4.2 はバージョン管理のアプリ更新から更新できます。アプリ内更新はポータブル ZIP を使用し、設定、認証情報、使用履歴を保持します。永続ストレージ対応版への初回更新は既存アプリのフォルダーで行い、既存データを登録してください。その後、保存先とバックアップから移動できます。

新規インストールには対応する x64 または ARM64 の Setup.exe を選択してください。旧 Custom 0.3.6 は上流のデスクトップ更新元を使用するため、手動移行が必要です。手動置換前にアプリとコアを終了し、既存フォルダーをバックアップしてください。Windows インストーラーは未署名です。
