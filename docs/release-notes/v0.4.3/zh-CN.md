# Custom 0.4.3

- 合并上游桌面版 **0.3.76**，内置官方 CLIProxyAPI **8.0.52**，包含智能体探测性能修复、额度改进、智能体用量历史、路由、MCP 与技能、主题及反向代理。
- 保留独立的 **Subscription Usage** 仪表盘、账号优先级、会话亲和性，以及按月生效的订阅费用和价格覆盖率报告。
- 在高级功能中新增存储与备份。数据位置可跨应用升级保留；经过校验的备份和恢复包含用量、费用、凭据、智能体历史、MCP 与技能配置、主题和偏好。SQLite 快照包含已提交的 WAL 记录。
- 除便携 ZIP 外，提供当前 Windows 用户安装的 **Setup.exe**。可复用现有便携数据目录；重装和卸载保留个人数据。
- 发布前修复继承自上游的界面、本地化、发布工具和 Windows 测试兼容性问题。
- 桌面更新与模型目录继续使用本 Custom 仓库；代理核心更新继续使用官方源。

## 更新

Custom 0.4.0/0.4.1/0.4.2 可通过版本管理中的应用更新升级。应用内更新使用便携 ZIP，保留设置、凭据和用量历史。首次升级到支持持久存储的版本时，请更新原应用目录，以便登记现有数据；之后可通过存储与备份迁移。

全新安装请选择对应 x64 或 ARM64 的 Setup.exe。旧 Custom 0.3.6 仍使用上游桌面更新源，需要手动迁移。手动替换前请关闭应用并停止核心，先备份原目录。Windows 安装程序未签名。
