# Custom 0.4.3

- 合併上游桌面版 **0.3.76**，內建官方 CLIProxyAPI **8.0.52**，包含智慧體偵測效能修復、額度改進、智慧體用量歷史、路由、MCP 與技能、主題及反向代理。
- 保留獨立的 **Subscription Usage** 儀表板、帳號優先順序、工作階段親和性，以及按月生效的訂閱費用與價格覆蓋率報告。
- 在進階功能中新增儲存與備份。資料位置可跨應用升級保留；經過驗證的備份與還原包含用量、費用、憑證、智慧體歷史、MCP 與技能設定、主題與偏好。SQLite 快照包含已提交的 WAL 記錄。
- 除可攜 ZIP 外，提供目前 Windows 使用者安裝的 **Setup.exe**。可沿用既有可攜資料目錄；重新安裝與解除安裝保留個人資料。
- 發布前修復繼承自上游的介面、在地化、發布工具及 Windows 測試相容性問題。
- 桌面更新與模型目錄繼續使用本 Custom 儲存庫；代理核心更新繼續使用官方來源。

## 更新

Custom 0.4.0/0.4.1/0.4.2 可透過版本管理中的應用更新升級。應用內更新使用可攜 ZIP，保留設定、憑證與用量歷史。首次升級至支援持久儲存的版本時，請更新原應用目錄，以便登記既有資料；之後可透過儲存與備份遷移。

全新安裝請選擇對應 x64 或 ARM64 的 Setup.exe。舊 Custom 0.3.6 仍使用上游桌面更新來源，需要手動遷移。手動替換前請關閉應用並停止核心，先備份原目錄。Windows 安裝程式未簽署。
